# LeetCode Notes

This repository stores my LeetCode solutions and algorithm notes, organized by topic.

## Structure

- `by-topic/array/`
- `by-topic/binary-search/`
- `by-topic/bit-manipulation/`
- `by-topic/dynamic-programming/`
- `by-topic/graph/`
- `by-topic/hash-table/`
- `by-topic/linked-list/`
- `by-topic/math/`
- `by-topic/stack-queue/`
- `by-topic/string/`
- `by-topic/tree/`
- `by-topic/two-pointers/`

Each solved problem is organized as:

```text
by-topic/<topic>/<problem-id>-<problem-slug>/
├── README.md
└── solution.cpp
```

`README.md` contains the problem summary and approach. `solution.cpp` contains the C++ implementation.
