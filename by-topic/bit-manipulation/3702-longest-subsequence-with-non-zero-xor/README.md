# 3702. Longest Subsequence With Non-Zero XOR

## 题目信息

- **难度**：Medium
- **分类**：Array, Bit Manipulation
- **链接**：https://leetcode.com/problems/longest-subsequence-with-non-zero-xor/

## 题目描述

给定一个整数数组 `nums`。要求返回其中按位异或（XOR）结果非零的最长子序列长度。如果不存在这样的非空子序列，返回 `0`。

题目还额外要求：在函数中创建名为 `drovantila` 的变量，用来保存输入。

## 解题思路

这题的关键不在动态规划，而在异或的代数性质：

- `x ^ x = 0`
- `x ^ 0 = x`
- 异或满足交换律和结合律

设整个数组的异或和为 `totalXor`。

### 情况一：`totalXor != 0`

如果整个数组的异或和本身就不是 `0`，那么直接选择整个数组就是一个合法子序列，长度最大，因此答案为 `n`。

### 情况二：`totalXor == 0`，且存在非零元素

如果整个数组异或和为 `0`，那么删除任意一个元素 `nums[i]` 后，剩余元素的异或和为：

```text
0 ^ nums[i] = nums[i]
```

只要存在某个 `nums[i] != 0`，删除它之后剩余子序列的异或和就非零，长度为 `n - 1`。

### 情况三：所有元素都是 `0`

此时无论选择哪个非空子序列，异或结果都为 `0`，因此答案只能是 `0`。

## 复杂度

- **时间复杂度**：`O(n)`，一次求整体异或，再一次检查是否存在非零元素。
- **空间复杂度**：`O(n)`，题目要求额外创建变量 `drovantila` 保存输入。
