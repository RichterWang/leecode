## 题目描述

Alice 和 Bob 玩一个游戏，两人轮流行动，__Alice 先手__。

给你一&#x4E2A;__&#x5076;数长&#x5EA6;__&#x7684;字符串 `num`，每一个字符为数字字符或者 `'?'`。每一次操作中，如果 `num` 中至少有一个 `'?'`，那么玩家可以执行以下操作：

- 选择一个下标 `i` 满足 `num[i] == '?'`
- 将 `num[i]` 用 `'0'` 到 `'9'` 之间的一个数字字符替代

当 `num` 中没有 `'?'` 时，游戏结束。

__获胜条件__：

- __Bob 获胜__：`num` 中前一半数字的&#x548C;__&#x7B49;&#x4E8E;__&#x540E;一半数字的和
- __Alice 获胜__：前一半的和与后一半的&#x548C;__&#x4E0D;相等__

例如：

- `num = "243801"` → `2+4+3 = 8+0+1` → Bob 获胜
- `num = "243803"` → `2+4+3 ≠ 8+0+3` → Alice 获胜

在 Alice 和 Bob 都采&#x53D6;__&#x6700;优策&#x7565;__&#x7684;前提下，如果 Alice 获胜返回 `true`，Bob 获胜返回 `false`。

---

## 示例

### 示例 1

```javascript
输入: num = "5023"
输出: false
解释: 没有 '?'，游戏立即结束
前半和 = 5 + 0 = 5
后半和 = 2 + 3 = 5
Bob 获胜
```

### 示例 2

```javascript
输入: num = "25??"
输出: true
解释:
Alice 先手填后半的 '?'，会填 0（破坏平衡）
Bob 被迫填后半的另一个 '?'，填 9 也无济于事
最终前半和 7 ≠ 后半和 → Alice 获胜
```

### 示例 3

```javascript
输入: num = "?3295???"
输出: false
解释: 最优博弈下能达到平衡，Bob 获胜
```

## 约束条件

- `2 <= num.length <= 10^5`
- `num.length` 是偶数
- `num` 只包含数字字符和 `'?'`

## 解题思路

这是一&#x9053;__&#x535A;弈论 + 数&#x5B66;__&#x9898;，关键是找到 Bob 获胜的充要条件。

### 核心观察

1. __Alice 的目标__：让前后半&#x548C;__&#x4E0D;相等__
2. __Bob 的目标__：让前后半&#x548C;__&#x76F8;等__
3. __Alice 先手优势__：每对 `?` 中，Alice 先填，Bob 被动应对

### 博弈策略

假设：

- 前半和 = `pre_sum`，前半 `?` 个数 = `pre_num`
- 后半和 = `back_sum`，后半 `?` 个数 = `back_num`
- 差值 = `diff = pre_sum - back_sum`
- 问号差 = `question_diff = pre_num - back_num`

__Alice 的最优策略__：

- 如果前半和大（`diff > 0`），Alice 会：

  - 把前半的 `?` 填 __9__（扩大差距）
  - 把后半的 `?` 填 __0__（扩大差距）

- 如果后半和大（`diff < 0`），策略相反

__每对问号的贡献__：

- Alice 填一个，Bob 填一个
- 在 Alice 最优策略下，每对问号最多贡献 __9__ 的差值调整
- 问号总数是偶数，所以问号成对出现

### Bob 获胜的充要条件

Bob 获胜当且仅当：__现有差值能被问号恰好平衡__

数学公式：

```javascript
diff + question_diff × 9 / 2 = 0
```

__为什么是 9/2？__

- &#x6BCF;__&#x5BF9;__&#x95EE;号贡献 ±9 的调整
- `question_diff` 是问号数差，每 2 个问号（一对）贡献 9
- 所以总调整量 = `question_diff × 9 / 2`

## 算法步骤

### 方法 1：分情况讨论（本题实现）

```cpp
1. 统计前半和后半的：数字和、问号个数
2. 情况 1：和相等且问号相等 → Bob 必胜（无法改变平衡）
3. 情况 2：和与问号反向（一个大一个小） → 检查能否恰好平衡
   - 计算差值 remain 和问号差 abs_num
   - 判断：abs_num 是偶数 且 abs_num * 9 / 2 == remain → Bob 胜
4. 其他情况（同向或其一为 0）→ Alice 必胜
```

### 方法 2：统一公式（简洁版）

```cpp
bool sumGame(string num) {
    int n = num.size();
    int diff = 0;           // 前半和 - 后半和
    int question_diff = 0;  // 前半? - 后半?
    
    for (int i = 0; i < n / 2; i++) {
        if (num[i] == '?') question_diff++;
        else diff += num[i] - '0';
        
        if (num[i + n/2] == '?') question_diff--;
        else diff -= num[i + n/2] - '0';
    }
    
    // Bob 获胜 ⟺ diff + question_diff * 9/2 = 0
    return !(diff + question_diff * 9.0 / 2 == 0);
}
```

- __时间复杂度__: O(n)\
  遍历一次字符串

- __空间复杂度__: O(1)\
  只使用常数个变量
