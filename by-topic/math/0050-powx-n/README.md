# 50. Pow(x, n)

**难度**：Medium　**标签**：数学、递归、快速幂

## 题目描述

实现 `pow(x, n)`，即计算 `x` 的整数 `n` 次幂函数（即 `x^n`）。

**示例**：

```text
输入：x = 2.00000, n = 10
输出：1024.00000

输入：x = 2.10000, n = 3
输出：9.26100

输入：x = 2.00000, n = -2
输出：0.25000
解释：2^-2 = 1/2^2 = 1/4 = 0.25
```

**约束**：

- `-100.0 < x < 100.0`
- `-2^31 <= n <= 2^31 - 1`
- `n` 是一个整数
- `-10^4 <= x^n <= 10^4`

## 核心思路：快速幂（二分幂）

朴素做法是循环乘 `n` 次，复杂度 `O(n)`。当 `n` 达到 `2^31 - 1` 时会超时。

**快速幂**利用指数的二进制表示，将复杂度降到 `O(log n)`。

### 数学原理

任何整数都可以表示为二进制：

```text
n = b_k * 2^k + b_{k-1} * 2^{k-1} + ... + b_1 * 2 + b_0
```

其中每个 `b_i` 是 0 或 1。

所以：

```text
x^n = x^(b_k * 2^k) * x^(b_{k-1} * 2^{k-1}) * ... * x^(b_1 * 2) * x^(b_0)
```

举例：`x^13 = x^(1101₂) = x^8 * x^4 * x^1`

**关键观察**：
- `x^(2^i)` 可以通过 `x^(2^{i-1})` 平方得到
- 只需要 `O(log n)` 次平方操作

### 算法流程

从 `n` 的最低位开始，逐位处理：

1. **检查当前位**：如果是 1，把当前的 `x` 累乘到结果里
2. **更新底数**：`x` 平方，准备下一位（对应更高的幂次）
3. **右移**：`n` 除以 2，处理下一位

```cpp
double result = 1.0;
while (n > 0) {
    if (n % 2 == 1) result *= x;   // 当前位是 1
    x *= x;                         // 底数平方
    n /= 2;                         // 右移
}
```

### 逐步演算：`x = 2, n = 13`

`13 = 1101₂`，期望 `2^13 = 8192`。

| 轮次 | `n` (十进制) | `n` (二进制) | 最低位 | `result` | `x` | `n` 右移后 |
|---|---|---|---|---|---|---|
| 初始 | 13 | `1101` | - | `1.0` | `2` | - |
| 1 | 13 | `1101` | 1 | `1 * 2 = 2` | `2^2 = 4` | `6` |
| 2 | 6 | `110` | 0 | `2` (不变) | `4^2 = 16` | `3` |
| 3 | 3 | `11` | 1 | `2 * 16 = 32` | `16^2 = 256` | `1` |
| 4 | 1 | `1` | 1 | `32 * 256 = 8192` | `256^2 = ...` | `0` |
| 退出 | 0 | - | - | **8192** ✓ | - | - |

每轮只做 1 次判断 + 1 次乘法 + 1 次除法，总共 `log₂(13) ≈ 4` 轮。

## 处理负指数

`x^(-n) = 1 / x^n`

转换思路：
1. 如果 `n < 0`，让 `x = 1 / x`，`n = -n`
2. 然后按正指数计算

```cpp
if (n < 0) {
    x = 1.0 / x;
    n = -n;
}
```

### 关键：`INT_MIN` 溢出问题

`int` 的范围是 `[-2^31, 2^31 - 1]`，即 `[-2147483648, 2147483647]`。

当 `n = INT_MIN = -2147483648` 时，`-n = 2147483648` **超出 `int` 的正数上限**（只能到 `2147483647`），导致溢出。

**解决办法**：用 `long long` 存储指数。

```cpp
long long exp = n;
if (exp < 0) {
    x = 1.0 / x;
    exp = -exp;   // 安全，long long 能容纳 2^31
}
```

`long long` 的范围是 `[-2^63, 2^63 - 1]`，`INT_MIN` 的相反数在这个范围内。

## 代码逐行解析

```cpp
double myPow(double x, int n) {
    long long exp = n;   // 用 long long 避免 abs(INT_MIN) 溢出
    
    if (n < 0) {
        exp = abs(exp);  // 转成正数
        x = 1.0 / x;     // 底数变倒数
    }
    
    double result = 1.0f;   // 累积器，初值是 1
    
    while (exp > 0) {
        if (exp % 2 == 1) result = result * x;   // 当前位是 1，累乘
        x = x * x;                                // 底数平方
        exp = exp / 2;                            // 右移一位
    }
    
    return result;
}
```

### 关键点

**1. `result` 初始化为 `1.0`**

任何数的 0 次方是 1，乘法累积器从 1 开始。

**2. `x` 每轮都要平方**

```cpp
x = x * x;   // 必须有，不能省略
```

这是快速幂的核心：`x` 的值依次是 `x^1, x^2, x^4, x^8, x^16, ...`，对应二进制的各个位。

**3. 三步顺序不能乱**

```cpp
if (exp % 2 == 1) result = result * x;   // 1. 先用当前的 x
x = x * x;                                // 2. 再更新 x
exp = exp / 2;                            // 3. 最后右移
```

- 先判断当前位是否为 1，决定要不要用**当前的** `x`
- 再让 `x` 平方，为下一位准备更高的幂次
- 最后右移指数

如果把 `x = x * x` 放在前面，当前轮用到的就是已经平方后的 `x`，逻辑就错了。

**4. 位运算优化（可选）**

```cpp
if (exp & 1) result *= x;   // 等价于 exp % 2 == 1
exp >>= 1;                   // 等价于 exp /= 2
```

位运算比取模和除法稍快，但可读性稍差。性能差距在本题数据范围下可忽略。

## 常见错误

### 错误 1：`result` 未初始化

```cpp
double result;   // ❌ 值是随机的垃圾数据
```

C++ 局部变量不会自动初始化为 0。必须显式写 `double result = 1.0;`。

### 错误 2：`abs(n)` 导致 `INT_MIN` 溢出

```cpp
if (n < 0) {
    n = abs(n);   // ❌ n = INT_MIN 时溢出
    x = 1.0 / x;
}
```

`abs(INT_MIN)` 的结果超出 `int` 范围，溢出后变成负数，导致错误。

**修复**：用 `long long`。

```cpp
long long exp = n;
if (exp < 0) {
    exp = -exp;   // 安全
    x = 1.0 / x;
}
```

### 错误 3：直接在 `x` 上操作，没有 `result`

```cpp
while (n > 0) {
    x = (n % 2 == 1) ? x * x * x : x * x;   // ❌ 逻辑错误
    n /= 2;
}
return x;
```

这会让 `x` 的含义被破坏——它既要当底数又要当结果，导致计算错误。

**正确做法**：用 `result` 累积答案，`x` 只负责平方。

### 错误 4：忘记让 `x` 平方

```cpp
while (n > 0) {
    if (n % 2 == 1) result *= x;
    n /= 2;
    // ❌ 缺少 x *= x;
}
```

`x` 一直是初始值，不会变成 `x^2, x^4, x^8, ...`，算法失效。

### 错误 5：`result = result * result * x`

```cpp
if (n % 2 == 1) {
    result = result * result * x;   // ❌ result 自己乘自己
}
```

这会让 `result` 指数级增长，逻辑完全错误。应该是：

```cpp
result = result * x;   // 或者 result *= x;
```

## 复杂度分析

- **时间复杂度**：`O(log n)`
  - 每轮 `n` 除以 2，最多循环 `log₂(n)` 次
  - `n` 最大 `2^31`，循环不超过 31 次
- **空间复杂度**：`O(1)`
  - 只用了常数个变量

相比朴素的 `O(n)` 循环乘法，快速幂在 `n` 很大时有巨大优势。

## 递归版本（备选）

快速幂也可以用递归实现，逻辑更直观：

```cpp
class Solution {
public:
    double myPow(double x, int n) {
        long long exp = n;
        if (exp < 0) {
            x = 1.0 / x;
            exp = -exp;
        }
        return quickPow(x, exp);
    }
    
private:
    double quickPow(double x, long long n) {
        if (n == 0) return 1.0;
        double half = quickPow(x, n / 2);
        return (n % 2 == 0) ? half * half : half * half * x;
    }
};
```

### 递归思路

```text
x^n = (x^(n/2))^2           如果 n 是偶数
x^n = (x^(n/2))^2 * x       如果 n 是奇数
```

每次把问题规模减半，递归深度 `O(log n)`。

### 递归 vs 迭代

| | 递归版 | 迭代版 |
|---|---|---|
| 可读性 | 更直观 | 稍复杂 |
| 空间 | `O(log n)` 栈空间 | `O(1)` |
| 性能 | 函数调用开销 | 无额外开销 |

LeetCode 上两者都能通过，但**迭代版更推荐**（省栈空间，无函数调用开销）。
