```markdown
# 3622. Check Divisibility by Digit Sum and Product

**难度**: Easy  
**标签**: Math, Number Theory, Digit Manipulation

## 题目描述

给你一个正整数 `n`。请判断 `n` 是否可以被以下两值之和整除：

- `n` 的**数字和**（即其各个位数之和）
- `n` 的**数字积**（即其各个位数之积）

如果 `n` 能被该和整除，返回 `true`；否则，返回 `false`。

---

## 示例

### 示例 1
```

输入: n = 12 输出: false 解释:

- 数字和 = 1 + 2 = 3
- 数字积 = 1 × 2 = 2
- 和 + 积 = 5
- 12 % 5 = 2 ≠ 0

```javascript

### 示例 2
```

输入: n = 36 输出: false 解释:

- 数字和 = 3 + 6 = 9
- 数字积 = 3 × 6 = 18
- 和 + 积 = 27
- 36 % 27 = 9 ≠ 0

```javascript

---

## 约束条件

- `1 <= n <= 10^9`

---

## 解题思路

这是一道简单的数学模拟题，核心是**提取整数的各位数字**。

### 方法：取模除法

**步骤**：
1. 用取模 `n % 10` 提取最低位
2. 用整除 `n /= 10` 去掉最低位
3. 在提取的同时累加数字和、累乘数字积
4. 最后判断 `n % (sum + prod) == 0`

**为什么不用 vector 存储？**
- 只需要遍历一次就能同时计算和与积，无需保存各位数字
- 节省空间复杂度：O(1) vs O(log n)

---

## 关键点

### 1. 溢出问题

题目约束 `n <= 10^9`，最坏情况是 9 位数字全为 9：
```

数字积 = 9^9 = 387,420,489 < 2^31 - 1 (约 21 亿)

```javascript
所以 `int` 类型足够，无需 `long long`。

唯一的 10 位数是 `10^9` 本身，包含 0，所以数字积为 0。

### 2. 除零问题

因为 `n >= 1`，所以：
- 数字和 `sum >= 1`
- `sum + prod >= 1`（积为 0 时和至少为 1）

**不存在除以 0 的风险**。

### 3. 含 0 的数字

如果 `n` 的某一位是 0，则：
- 数字积 `prod = 0`
- 判断条件退化成 `n % sum == 0`

逻辑天然正确，无需特殊处理。

---

## 复杂度分析

- **时间复杂度**: O(log n)  
  需要提取 log₁₀(n) 位数字

- **空间复杂度**: O(1)  
  只使用常数个变量
```
