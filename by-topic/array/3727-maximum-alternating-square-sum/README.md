# 3727. 最大交替平方和

## 题目信息

- **难度**：Medium
- **分类**：Array, Greedy, Sorting
- **链接**：https://leetcode.com/problems/maximum-alternating-square-sum/

## 题目描述

给你一个整数数组 `nums`。你可以以任意顺序**重新排列元素**。

数组 `arr` 的**交替得分**定义为：

```
score = arr[0]² - arr[1]² + arr[2]² - arr[3]² + ...
```

在对 `nums` 重新排列后，返回其**最大可能的交替得分**。

## 解题思路

### 核心观察

交替得分的公式是：偶数位置的平方和减去奇数位置的平方和。

要最大化这个值，关键在于：
1. **所有数的平方都是非负的**（无论正负，平方后都是正数）
2. 要让"加号位置"的贡献尽可能大，"减号位置"的贡献尽可能小

### 贪心策略

由于平方函数的特性，`(-3)² = 3² = 9`，所以**负数和正数的绝对值相同时，对答案的贡献也相同**。

因此正确的策略是：
- **按绝对值降序排序**
- 将**绝对值大的数**放在加号位置（偶数下标 0, 2, 4, ...）
- 将**绝对值小的数**放在减号位置（奇数下标 1, 3, 5, ...）

### 具体实现

设数组长度为 `n`：
- 加号位置的个数：`(n + 1) / 2`（向上取整）
- 减号位置的个数：`n / 2`（向下取整）

算法步骤：
1. 按绝对值从大到小排序
2. 前 `(n + 1) / 2` 个数的平方相加
3. 后 `n / 2` 个数的平方相减

### 为什么这样是最优的？

考虑任意两个数 `a` 和 `b`，假设 `|a| > |b|`：
- 如果 `a` 在加号位置，`b` 在减号位置：贡献 = `a² - b²`
- 如果 `a` 在减号位置，`b` 在加号位置：贡献 = `b² - a²`

显然 `a² - b² > b² - a²`，所以绝对值大的应该放在加号位置。

## 示例分析

### 示例 1：`[1, 2, 3]`

按绝对值排序：`[3, 2, 1]`
- 加号位置（前 2 个）：`3² + 2² = 9 + 4 = 13`
- 减号位置（后 1 个）：`1² = 1`
- 结果：`13 - 1 = 12`

### 示例 2：`[1, -1, 2, -2, 3, -3]`

按绝对值排序：`[3, -3, 2, -2, 1, -1]`（或其他绝对值相同的排列）
- 加号位置（前 3 个）：`3² + (-3)² + 2² = 9 + 9 + 4 = 22`
- 减号位置（后 3 个）：`(-2)² + 1² + (-1)² = 4 + 1 + 1 = 6`
- 结果：`22 - 6 = 16`

## 复杂度分析

**时间复杂度**：`O(n log n)`  
主要开销在排序，后续遍历是 `O(n)`。

**空间复杂度**：`O(log n)`  
排序的递归栈空间（原地排序）。

## 易错点

1. **忘记考虑负数的平方**：负数平方后变正数，所以要按绝对值排序而不是按原值排序
2. **加减位置计算错误**：注意 `n` 为奇数时，加号位置比减号位置多一个
3. **整型溢出**：平方后的值可能很大，需要用 `long long` 类型
