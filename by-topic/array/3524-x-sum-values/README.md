# 3524. 求出数组的 X 值 I

- **难度**：Medium
- **标签**：数组、前缀和、哈希表、数学、模运算

## 问题描述

给你一个由**正整数**组成的数组 `nums`，以及一个**正整数** `k`。

你可以对 `nums` 执行**一次**操作，该操作中可以移除任意**不重叠**的前缀和后缀，使得 `nums` 仍然**非空**。

你需要找出 `nums` 的 **X 值**，即在执行操作后，剩余元素的**乘积**除以 `k` 后的**余数**为 `x` 的操作数量。

返回一个大小为 `k` 的数组 `result`，其中 `result[x]` 表示对于 `0 <= x <= k - 1`，`nums` 的 `x` 值。

### 定义

- **前缀**：从数组起始位置开始到数组中任意位置的一段连续子数组
- **后缀**：从数组中任意位置开始到数组末尾的一段连续子数组
- **注意**：在操作中选择的前缀和后缀可以是**空的**

### X 值的含义

对于每个可能的余数 `x`（范围是 `0` 到 `k-1`），统计有**多少种操作方式**能让剩余元素的乘积除以 `k` 后的余数等于 `x`。

### 示例 1

```text
输入：nums = [2, 3, 4, 5], k = 6

可能的操作：
- 不移除：[2,3,4,5] → 乘积=120 → 120 % 6 = 0
- 移除前缀[2]：[3,4,5] → 乘积=60 → 60 % 6 = 0
- 移除前缀[2,3]：[4,5] → 乘积=20 → 20 % 6 = 2
- 移除后缀[5]：[2,3,4] → 乘积=24 → 24 % 6 = 0
- 移除前缀[2]+后缀[5]：[3,4] → 乘积=12 → 12 % 6 = 0
... 等等

输出：[计数余数为0的次数, 计数余数为1的次数, ..., 计数余数为5的次数]
```

### 约束条件

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 50`

## 解法分析

### 方法 1：双层循环暴力枚举（推荐）

**文件**：`solution_brute_force.cpp`

#### 核心思路

- 枚举所有可能的子数组 `[left, right]`
- 每个子数组对应一种"移除前缀 `[0, left-1]` 和后缀 `[right+1, n-1]`"的操作
- 直接计算子数组元素乘积对 `k` 取模

#### 代码实现

```cpp
vector<long long> resultArray(vector<int>& nums, int k) {
    int n = nums.size();
    vector<long long> answer(k, 0);
    
    // 枚举所有可能的子数组 [left, right]
    for (int left = 0; left < n; left++) {
        long long product = 1;
        for (int right = left; right < n; right++) {
            product = (product * nums[right]) % k;  // 边乘边取模
            answer[product]++;
        }
    }
    
    return answer;
}
```

#### 复杂度分析

- **时间复杂度**：O(n²)
  - 外层循环 `left`：O(n)
  - 内层循环 `right`：O(n)
  - 总共枚举 `n(n+1)/2` 个子数组
  
- **空间复杂度**：O(k)
  - 只需要大小为 `k` 的结果数组

#### 优缺点

✅ **优点**：
- 逻辑简单清晰
- 避免了除法在模运算中的问题
- 边乘边取模防止溢出
- 代码易于理解和实现

❌ **缺点**：
- 时间复杂度 O(n²)，对于 `n = 1000` 可能会超时
- 需要进一步优化

### 方法 2：前后缀积（存在问题的初始实现）

**文件**：`solution_prefix_suffix.cpp`

#### 核心思路

- 预计算前缀积和后缀积
- 通过 `total / (prefix[front] * suffix[back])` 计算剩余元素的乘积
- 枚举所有可能的前后缀移除方案

#### 存在的问题

1. **除法在模运算中不适用**
   ```cpp
   (total / (prefix[front] * suffix[back])) % k
   ```
   - 模运算不支持直接除法
   - 需要使用乘法逆元，但 `k` 不一定是质数

2. **逻辑错误**
   ```cpp
   if((total / (prefix[front] * suffix[back])) % k == (back + front))
   ```
   - 错误地将余数与操作数 `(front + back)` 进行比较
   - 应该是统计每个余数的出现次数

3. **效率问题**
   - 三层循环：O(n² × k)
   - 比暴力枚举还要慢

#### 为什么除法在模运算中不适用？

**模运算的基本性质**：
- ✅ 加法：`(a + b) % m = ((a % m) + (b % m)) % m`
- ✅ 乘法：`(a * b) % m = ((a % m) * (b % m)) % m`
- ❌ 除法：`(a / b) % m ≠ ((a % m) / (b % m)) % m`

**反例**：
```cpp
total = 120, divisor = 24, k = 7

// 方法1：先除后取模
(120 / 24) % 7 = 5 % 7 = 5  ✅

// 方法2：先取模再除（错误！）
((120 % 7) / (24 % 7)) % 7 = (1 / 3) % 7 = 0  ❌
```

**原因**：取模会"丢失信息"，破坏了除法关系。

### 方法 3：动态规划（最优解）⭐⭐⭐⭐⭐

**文件**：`solution_dp.cpp`

#### 核心思路

**状态定义**：
```cpp
dp[i][j] = 以位置 i 结尾、乘积 % k 余数为 j 的子数组数量
```

**状态转移**：
对于位置 `i`，有两种情况：

1. **单独成子数组**：`[i]`
   - 余数 = `nums[i] % k`
   - 贡献 1 个子数组

2. **接在前面的子数组后面**：`[...j, i]`
   - 如果 `dp[i-1][j] > 0`（存在以 `i-1` 结尾、余数为 `j` 的子数组）
   - 新余数 = `(j * (nums[i] % k)) % k`
   - 贡献 `dp[i-1][j]` 个子数组

#### 代码实现

```cpp
vector<long long> resultArray(vector<int>& nums, int k) {
    int n = nums.size();
    vector<long long> answer(k, 0);
    
    // dp[i][j] = 以位置 i 结尾、余数为 j 的子数组数量
    vector<vector<long long>> dp(n, vector<long long>(k, 0));
    
    // 初始化第一个元素
    dp[0][nums[0] % k] = 1;
    answer[nums[0] % k]++;
    
    // 动态规划
    for (int i = 1; i < n; i++) {
        int cur_mod = nums[i] % k;
        
        // 情况1：单独成为子数组 [i]
        dp[i][cur_mod]++;
        
        // 情况2：接在前面的子数组后面
        for (int j = 0; j < k; j++) {
            if (dp[i-1][j] > 0) {
                // 新余数 = (前面的余数 * 当前元素) % k
                int new_mod = (j * cur_mod) % k;
                dp[i][new_mod] += dp[i-1][j];
            }
        }
        
        // 统计以 i 结尾的所有子数组
        for (int j = 0; j < k; j++) {
            answer[j] += dp[i][j];
        }
    }
    
    return answer;
}
```

#### 执行过程示例

假设 `nums = [2, 3, 4], k = 6`

**初始化（i=0）**：
```
nums[0] = 2, mod = 2
dp[0][2] = 1  // 子数组 [2]
answer[2] = 1
```

**i=1（nums[1]=3）**：
```
cur_mod = 3

情况1：单独成子数组
dp[1][3] = 1  // 子数组 [3]

情况2：接在前面的子数组后面
dp[0][2] = 1 存在
new_mod = (2 * 3) % 6 = 0
dp[1][0] += 1  // 子数组 [2,3]

统计：
answer[3] += 1  // [3]
answer[0] += 1  // [2,3]
```

**i=2（nums[2]=4）**：
```
cur_mod = 4

情况1：单独成子数组
dp[2][4] = 1  // 子数组 [4]

情况2：接在前面的子数组后面
- dp[1][3] = 1 存在
  new_mod = (3 * 4) % 6 = 0
  dp[2][0] += 1  // 子数组 [3,4]

- dp[1][0] = 1 存在
  new_mod = (0 * 4) % 6 = 0
  dp[2][0] += 1  // 子数组 [2,3,4]

统计：
answer[4] += 1  // [4]
answer[0] += 2  // [3,4], [2,3,4]
```

**最终结果**：
```
answer[0] = 3  // [2,3], [3,4], [2,3,4]
answer[2] = 1  // [2]
answer[3] = 1  // [3]
answer[4] = 1  // [4]
```

#### 空间优化：滚动数组

由于 `dp[i]` 只依赖 `dp[i-1]`，可以用滚动数组优化空间：

```cpp
vector<long long> dp(k, 0);  // 只需要一维数组

for (int i = 1; i < n; i++) {
    vector<long long> new_dp(k, 0);  // 新的一层
    
    // 单独成子数组
    new_dp[cur_mod]++;
    
    // 接在前面的子数组后面
    for (int j = 0; j < k; j++) {
        if (dp[j] > 0) {
            int new_mod = (j * cur_mod) % k;
            new_dp[new_mod] += dp[j];
        }
    }
    
    dp = new_dp;
}
```

#### 复杂度分析

- **时间复杂度**：O(n × k)
  - 外层循环 n 次
  - 内层枚举 k 个余数
  - 当 `k` 较小时（本题 k ≤ 50），比 O(n²) 快约 20 倍
  
- **空间复杂度**：
  - 二维 DP：O(n × k)
  - 滚动数组优化：O(k)

#### 优缺点

✅ **优点**：
- **时间复杂度优秀**：O(n × k) << O(n²)（当 k 较小时）
- 逻辑清晰，状态转移明确
- 边乘边取模，避免溢出
- 无除法操作，完全规避模运算与除法的兼容性问题
- 空间可优化为 O(k)

✅ **适用场景**：
- k 较小（本题 k ≤ 50）
- n 较大（本题 n ≤ 1000）

#### 性能对比

| 方法 | 时间复杂度 | n=1000, k=50 时的操作数 |
|------|-----------|----------------------|
| 暴力枚举 | O(n²) | ~10⁶ |
| 动态规划 | O(n × k) | ~5×10⁴ |

**提速约 20 倍！**

## 核心知识点

### 1. 模运算的性质

- ✅ 加法：`(a + b) % m = ((a % m) + (b % m)) % m`
- ✅ 乘法：`(a * b) % m = ((a % m) * (b % m)) % m`
- ❌ 除法：`(a / b) % m ≠ ((a % m) / (b % m)) % m`

### 2. 为什么除法在模运算中不适用？

**反例**：
```cpp
total = 120, divisor = 24, k = 7

// 正确：先除后取模
(120 / 24) % 7 = 5 % 7 = 5  ✅

// 错误：先取模再除
((120 % 7) / (24 % 7)) % 7 = (1 / 3) % 7 = 0  ❌
```

**原因**：取模会"丢失信息"，破坏了除法关系。

### 3. 动态规划的状态设计

- **关键**：状态要能表示所有需要的信息
- **本题**：以位置 `i` 结尾 + 余数 `j` → 完整描述子数组的性质
- **转移**：利用乘法的模运算性质进行状态更新
