# 2089. Find Target Indices After Sorting Array

## 题目信息

- **难度**：Easy
- **分类**：Array, Binary Search, Sorting
- **链接**：https://leetcode.com/problems/find-target-indices-after-sorting-array/

## 题目描述

给定一个下标从 0 开始的整数数组 `nums` 以及一个目标元素 `target`。

目标下标是一个满足 `nums[i] == target` 的下标 `i`。

将 `nums` 按**非递减**顺序排序后，返回由 `nums` 中目标下标组成的列表。如果不存在目标下标，返回一个**空**列表。返回的列表必须按**递增**顺序排列。

## 解题思路

### 方法 1：直接排序（朴素解法）

1. 对数组排序
2. 遍历排序后的数组，找出所有等于 `target` 的元素的索引

**时间复杂度**：O(n log n)  
**空间复杂度**：O(1)

### 方法 2：计数优化（推荐）⭐

**核心观察**：排序后 `target` 的位置取决于：
- 有多少个元素**小于** `target`（决定起始位置）
- 有多少个元素**等于** `target`（决定有几个索引）

**算法步骤**：
1. 遍历数组，统计小于 `target` 的元素个数 `less_count` 和等于 `target` 的元素个数 `equal_count`
2. 排序后，`target` 的索引范围是 `[less_count, less_count + equal_count)`
3. 生成这个范围内的所有索引即可

**优势**：不需要真正排序，只需要一次遍历。

## 示例

### 示例 1
```
输入：nums = [1,2,5,2,3], target = 2
输出：[1,2]

解释：
排序后：[1, 2, 2, 3, 5]
           ↑  ↑
         索引1 索引2
```

### 示例 2
```
输入：nums = [1,2,5,2,3], target = 3
输出：[3]

解释：
排序后：[1, 2, 2, 3, 5]
                  ↑
                索引3
```

### 示例 3
```
输入：nums = [1,2,5,2,3], target = 5
输出：[4]
```

### 示例 4
```
输入：nums = [1,2,5,2,3], target = 4
输出：[]

解释：排序后数组中没有 4，返回空列表
```

## 代码中的边界

- 如果 `equal_count == 0`，说明没有元素等于 `target`，循环不执行，返回空数组
- 不需要处理空数组的特殊情况，因为空数组遍历后 `equal_count` 自然为 0

## 复杂度

- **时间复杂度**：O(n)，只需要一次遍历统计
- **空间复杂度**：O(1)，只使用了常数额外空间（不计结果数组）
