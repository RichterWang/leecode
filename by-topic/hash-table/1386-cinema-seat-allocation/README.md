# 1386. Cinema Seat Allocation

## 题目信息

- **难度**：Medium
- **分类**：Array, Hash Table, Greedy
- **链接**：https://leetcode.com/problems/cinema-seat-allocation/

## 题目描述

电影院有 `n` 排座位，每排编号从 `1` 到 `n`。每排有 10 个座位，编号从 `1` 到 `10`。

给定整数 `n` 和数组 `reservedSeats`，表示已被预订的座位 `[row, seat]`。

一个四人家庭可以坐在以下三种连续座位组合之一：

- `[2, 3, 4, 5]`
- `[4, 5, 6, 7]`
- `[6, 7, 8, 9]`

返回最多可以安排多少个四人家庭。

## 解题思路（初版）

这是一个贪心问题。对于每一行：

1. 记录哪些座位已被预订
2. 从左到右尝试放置家庭组
3. 每次成功放置一组后，标记这些座位已被占用
4. 统计总共能放置多少组

本版本使用二维数组 `map[n][10]` 记录所有座位状态。

### 当前实现的核心逻辑

1. 将所有预订座位标记在二维数组中
2. 对每一行，枚举可能的起点 `j`
3. 检查从 `j` 开始的连续 4 个座位是否全部空闲
4. 如果可用，标记这 4 个座位并计数

### 问题

**当前版本存在严重的内存问题**：

当 `n` 很大（如 `10^9`）时，`vector<vector<bool>> map(n, vector<bool>(10, 0))` 会尝试分配约 10GB 内存，导致内存超限（Out of Memory）。

## 优化方向

应该使用 `unordered_map` 只记录有预订的行：

```cpp
unordered_map<int, vector<bool>> rowMap;
```

然后：

1. 先计算有预订的行能放多少组
2. 空行每行可以放 2 组（`[2,3,4,5]` 和 `[6,7,8,9]`）
3. 最终答案 = 有预订行的贡献 + 空行数 × 2

## 复杂度（当前版本）

- **时间复杂度**：`O(n * 10)`
- **空间复杂度**：`O(n * 10)` ⚠️ 当 `n` 很大时会超限
