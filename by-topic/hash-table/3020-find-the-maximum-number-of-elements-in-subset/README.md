# 3020. Find the Maximum Number of Elements in Subset

## 题目信息

- **难度**：Medium
- **分类**：Array, Hash Table, Math, Greedy
- **链接**：https://leetcode.com/problems/find-the-maximum-number-of-elements-in-subset/

## 题目描述

从数组中选出尽可能多的元素，组成形如：

`x, x, x^2, x^2, x^4, x^4, ..., y`

的合法结构。除了最后一层只需要一个元素之外，中间每一层都需要两个相同元素。

## 解题思路

### 核心观察

如果把某个数 `x` 作为起点，就会形成一条平方链：

`x -> x^2 -> x^4 -> x^8 -> ...`

构造规则是：

- 中间层至少需要两个相同元素，才能继续向上扩展
- 最后一层只需要一个元素，就能作为链顶结束
- 因此合法答案长度总是奇数

### 特殊情况：1

`1^2 = 1`，平方后仍然是自己，所以不能按普通数那样向上扩展。

如果 `1` 出现了 `cnt` 次：

- `cnt` 为奇数：最多取 `cnt`
- `cnt` 为偶数：最多取 `cnt - 1`

### 一般情况

1. 用哈希表统计每个数出现次数
2. 枚举每个数作为链起点
3. 当当前值出现次数大于 1 时，可以作为中间层，长度 `+2`
4. 平方后继续检查下一层
5. 如果某层恰好有 1 个，可以作为顶层，长度再 `+1`
6. 否则最后一层不能成立，需要回退成合法奇数长度

**时间复杂度**：O(n * log log M) 到 O(n * 链长)  
**空间复杂度**：O(n)
