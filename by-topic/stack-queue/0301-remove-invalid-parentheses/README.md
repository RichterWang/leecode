# 301. 删除无效的括号

## 题目描述

给你一个由若干括号和字母组成的字符串 `s`，删除最小数量的无效括号，使得输入的字符串有效。

返回所有可能的结果。答案可以按**任意顺序**返回。

## 示例

### 示例 1

**输入：** `s = "()())()"`  
**输出：** `["(())()","()()()"]`

### 示例 2

**输入：** `s = "(a)())()"`  
**输出：** `["(a())()","(a)()()"]`

### 示例 3

**输入：** `s = ")("`  
**输出：** `[""]`

## 提示

- `1 <= s.length <= 25`
- `s` 由小写英文字母以及括号 `'('` 和 `')'` 组成
- `s` 中至多含 `20` 个括号

## 解题思路

### 核心算法：BFS + 剪枝

这道题的关键是要找到**删除最少数量的括号**使字符串有效，并返回**所有可能的结果**。

#### 为什么用 BFS？

1. **天然分层**：BFS 按删除数量分层搜索
   - 第 0 层：原字符串（删除 0 个）
   - 第 1 层：所有删除 1 个括号的字符串
   - 第 k 层：所有删除 k 个括号的字符串

2. **保证最优**：一旦某一层找到有效解，就停止搜索
   - 该层的所有有效解都是删除最少数量的结果

3. **避免重复**：使用哈希表去重

#### 算法流程

```text
1. 初始化队列，放入原字符串
2. 按层遍历：
   - 对当前层的每个字符串：
     * 检查是否有效 → 有效则加入结果
     * 如果本层未找到有效解，生成下一层：
       - 尝试删除每个括号（不删字母）
       - 跳过连续相同的括号（剪枝）
       - 用哈希表去重
3. 如果本层找到有效解，停止扩展下一层
```

#### 关键剪枝技巧

##### 1. 只删除括号

```cpp
if (cur[i] != '(' && cur[i] != ')') continue;
```

字母不影响括号的有效性，无需删除。

##### 2. 连续相同括号只删一次

```cpp
if (i > 0 && cur[i] == cur[i-1]) continue;
```

**原因**：对于 `"((("` ，删除第 0、1、2 个 `'('` 的结果相同，只需删除一次。

```text
"(((" 删索引 0: "(" ← 保留
"(((" 删索引 1: "(" ← 重复，跳过
"(((" 删索引 2: "(" ← 重复，跳过
```

##### 3. 哈希表去重

```cpp
unordered_set<string> visited;
if (!visited.count(next)) {
    q.push(next);
    visited.insert(next);
}
```

防止同一字符串被重复处理。

#### 括号有效性判断

使用 **balance 计数器**：

```cpp
bool isValid(const string& s) {
    int count = 0;
    for (char c : s) {
        if (c == '(') count++;
        else if (c == ')') {
            count--;
            if (count < 0) return false;  // 右括号过多
        }
    }
    return count == 0;  // 左右括号数量相等
}
```

**有效条件**：
1. 任何时刻 `count >= 0`（右括号不能超过左括号）
2. 最终 `count == 0`（左右括号数量相等）

## 复杂度分析

### 时间复杂度

- **最坏情况**：`O(n × 2^n)`
  - 最多有 `2^n` 个子序列
  - 每个字符串需要 `O(n)` 时间判断有效性
- **实际情况**：由于剪枝，远小于理论最坏情况

### 空间复杂度

- `O(n × 2^n)`
  - 队列和哈希表存储字符串

## 示例图解

### 示例：`"()())()"`

```text
第 0 层:
"()())()" → 无效（多 1 个 ')'）

第 1 层（删除 1 个括号）:
")())()"  → 无效
"()()()"  → 有效 ✓
"(())()"  → 有效 ✓
"()())()" → 重复
"()()()"  → 重复
"()())("  → 无效
"()()))"  → 无效

找到有效解，停止搜索
返回: ["()()()", "(())()"]
```

## 核心要点

1. **BFS 按层搜索** → 保证找到删除最少的解
2. **found 标志** → 本层找到有效解后停止扩展
3. **visited 去重** → 避免重复处理
4. **连续相同括号剪枝** → 减少冗余计算
5. **balance 判断** → 高效检查括号有效性
