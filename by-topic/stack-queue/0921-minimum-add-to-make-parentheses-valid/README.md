# 921. Minimum Add to Make Parentheses Valid

- **中文名称**：使括号有效的最少添加
- **题目链接**：https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/
- **核心思路**：双计数器分别统计需要补充的左右括号数量。

## 题目

给定一个由 `'('` 和 `')'` 组成的字符串 `s`，返回使 `s` 变为有效括号字符串所需添加的**最少括号数**。

有效括号字符串的定义：
- 空字符串或只包含小写字母的字符串是有效的
- 如果 `A` 和 `B` 是有效的，则 `AB` 也是有效的
- 如果 `A` 是有效的，则 `(A)` 也是有效的

```text
示例：
"())"     → 1  (需要在开头加 1 个 '(')
"((("     → 3  (需要在末尾加 3 个 ')')
"())(("   → 4  (需要 2 个 '(' 和 2 个 ')')
"()"      → 0  (已经有效)
```

## 核心思路

用两个计数器分别追踪两类不匹配情况：

| 变量 | 含义 | 何时增加 |
|------|------|---------|
| `balance` | 当前未匹配的左括号数 | 遇到 `(` 时 +1，遇到 `)` 时 -1 |
| `additions` | 需要补充的左括号数 | 当 `balance < 0` 时（右括号过多） |

### 为什么返回 `additions + balance`

这两个变量分别统计了两个方向的需求：

1. **`additions`**：统计右括号过多的情况
   - 当 `balance < 0` 时，说明出现了没有对应左括号的右括号
   - 需要在前面补充左括号
   
2. **`balance`**：统计左括号过多的情况
   - 扫描结束时，`balance > 0` 说明有左括号未被匹配
   - 需要在末尾补充右括号

**两者缺一不可**，因为一个字符串可能同时存在两种不匹配。

## 实现

```cpp
int minAddToMakeValid(string s) {
    int balance = 0;    // 未匹配的左括号数
    int additions = 0;  // 需要补充的左括号数
    
    for (char c : s) {
        if (c == '(') {
            balance++;
        } else {
            balance--;
            if (balance < 0) {
                additions++;   // 右括号过多
                balance = 0;   // 重置，继续扫描
            }
        }
    }
    
    return additions + balance;
}
```

## 详细示例：`"()))(("

| 字符 | balance | additions | 说明 |
|------|---------|-----------|------|
| 初始 | 0 | 0 | - |
| `(` | 1 | 0 | 未匹配左括号 +1 |
| `)` | 0 | 0 | 匹配成功 |
| `)` | -1 → 0 | 1 | 右括号多了，需要补 `(` |
| `)` | -1 → 0 | 2 | 又多一个，再补 `(` |
| `(` | 1 | 2 | 未匹配左括号 +1 |
| `(` | 2 | 2 | 未匹配左括号 +1 |
| **结束** | **2** | **2** | - |

**最终答案** = `2 + 2 = 4`

- 需要在前面补 2 个 `(`（对应 `additions`）
- 需要在末尾补 2 个 `)`（对应 `balance`）

补充后的字符串：`"((" + "()))((" + "))"`  → `"(()()))(())"`

## 为什么不能只返回 `additions`

考虑 `"((("` 这种情况：

| 字符 | balance | additions |
|------|---------|-----------|
| `(` | 1 | 0 |
| `(` | 2 | 0 |
| `(` | 3 | 0 |
| 结束 | **3** | **0** |

- `additions = 0`（因为 `balance` 从未 < 0）
- 但实际需要补 3 个 `)`
- 只返回 `additions` 会得到 0，显然是错的

**正确答案** = `additions + balance = 0 + 3 = 3`

## 为什么不能只返回 `balance`

考虑 `")))"` 这种情况：

| 字符 | balance | additions |
|------|---------|-----------|
| `)` | -1 → 0 | 1 |
| `)` | -1 → 0 | 2 |
| `)` | -1 → 0 | 3 |
| 结束 | **0** | **3** |

- `balance = 0`（每次 < 0 后都重置了）
- 但实际需要补 3 个 `(`
- 只返回 `balance` 会得到 0，显然是错的

**正确答案** = `additions + balance = 3 + 0 = 3`

## 复杂度

- **时间复杂度**：`O(n)`，单次遍历
- **空间复杂度**：`O(1)`，只用了两个变量

## 为什么不用栈

这题可以用栈实现（LeetCode 20 的变体），但计数器更优：

| 方法 | 时间 | 空间 | 实现复杂度 |
|------|------|------|-----------|
| 栈 | O(n) | O(n) | 需要维护栈结构 |
| 双计数器 | O(n) | O(1) | 只需两个变量 |

**栈的实现思路**（参考）：
```cpp
// 用栈统计未匹配的括号
stack<char> stk;
int additions = 0;

for (char c : s) {
    if (c == '(') {
        stk.push(c);
    } else {
        if (stk.empty()) {
            additions++;  // 右括号过多
        } else {
            stk.pop();    // 匹配成功
        }
    }
}

return additions + stk.size();  // 右括号过多 + 左括号过多
```

但这需要 `O(n)` 空间，而计数器只需 `O(1)`。

## 关键点总结

1. **双向统计**：一个字符串可能同时存在「右括号过多」和「左括号过多」
2. **即时处理**：右括号过多时立即累加 `additions` 并重置 `balance`
3. **延迟统计**：左括号过多要到扫描结束才能统计（`balance` 的最终值）
4. **空间优化**：用计数器代替栈，从 `O(n)` 降到 `O(1)`
