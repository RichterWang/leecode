# 1541. 平衡括号字符串的最小插入次数

## 题目描述

给你一个括号字符串 `s`，它只包含字符 `'('` 和 `')'`。一个括号字符串被称为**平衡的**当它满足：

- 任何左括号 `'('` 必须对应**两个连续的右括号** `'))'`
- 左括号 `'('` 必须在对应的连续两个右括号 `'))'` 之前

比方说 `"())"`、`"())(())))"` 和 `"(())())))"` 都是平衡的，`")("`、`"()))"`  和 `"(())))"` 都是不平衡的。

你可以在任意位置插入字符 `'('` 和 `')'` 使字符串平衡。

请你返回让 `s` 平衡的**最少插入次数**。

## 示例

### 示例 1

**输入：** `s = "(()))"`  
**输出：** `1`

**解释：** 第二个左括号有对应的两个右括号，但是第一个左括号只有一个右括号。我们需要在字符串结尾额外增加一个 `')'` 使字符串变成平衡字符串 `"(())))"` 。

### 示例 2

**输入：** `s = "())"`  
**输出：** `0`

**解释：** 字符串已经平衡了。

### 示例 3

**输入：** `s = "))())("`  
**输出：** `3`

**解释：** 添加 `'('` 去匹配最开头的 `'))'`，然后添加 `'))'` 去匹配最后一个 `'('`。

### 示例 4

**输入：** `s = "(((((("` 
**输出：** `12`

**解释：** 添加 12 个 `')'` 得到平衡字符串。

### 示例 5

**输入：** `s = ")))))))"`  
**输出：** `5`

**解释：** 在字符串开头添加 4 个 `'('` 和在结尾添加 1 个 `')'` 使字符串平衡。字符串变成 `"(())(())(()))"` 。

## 提示

- `1 <= s.length <= 10^5`
- `s` 只包含 `'('` 和 `')'`

## 解题思路

### 核心思想：贪心 + 平衡计数

这道题的关键在于理解**特殊的括号匹配规则**：
- 每个 `'('` 需要配对**两个连续**的 `')'`
- 这与常规括号匹配（1对1）不同

### 算法设计

使用两个变量：
1. **`balance`**：当前需要多少个 `')'` 来匹配前面的 `'('`
2. **`insertions`**：需要插入的字符总数

### 核心逻辑

#### 1. 遇到左括号 `'('`

```cpp
balance += 2;  // 每个 '(' 需要 2 个 ')' 来匹配
```

#### 2. 遇到右括号 `')'`

需要分两种情况处理：

##### 情况 A：连续两个 `'))'`

```cpp
if (i + 1 < n && s[i + 1] == ')') {
    balance -= 2;  // 消耗 2 个需求
    i += 2;        // 跳过两个字符
}
```

##### 情况 B：单独的 `')'`

```cpp
else {
    balance -= 2;     // 消耗 2 个需求
    i++;
    insertions++;     // 需要插入一个 ')' 配对
}
```

**为什么单独的 `')'` 要插入一个 `')'`？**

因为规则要求必须是**两个连续**的 `'))'`，单独的 `')'` 需要补一个才能满足规则。

#### 3. 处理右括号过多的情况

```cpp
while (balance < 0) {
    insertions++;   // 插入一个 '('
    balance += 2;   // 这个新的 '(' 需要 2 个 ')'
}
```

当 `balance < 0` 时，说明右括号太多了，需要在前面插入 `'('` 来匹配。

#### 4. 处理剩余未匹配的左括号

```cpp
return insertions + balance;
```

循环结束后，如果 `balance > 0`，说明还有左括号没有配对，需要插入 `balance` 个右括号。

### 图解示例

#### 示例：`"))())("`

```text
初始: balance = 0, insertions = 0

i=0: ')' → 检查下一个，也是 ')'
     → balance = 0 - 2 = -2
     → i = 2
     → balance < 0，需要插入 '('
     → insertions = 1, balance = -2 + 2 = 0

i=2: '(' → balance = 0 + 2 = 2
     → i = 3

i=3: ')' → 检查下一个，也是 ')'
     → balance = 2 - 2 = 0
     → i = 5

i=5: '(' → balance = 0 + 2 = 2
     → i = 6

结束: balance = 2（还需要 2 个 ')'）
返回: insertions + balance = 1 + 2 = 3
```

**最终字符串：** `"(()))(()))"`（插入了 1 个 `'('` 和 2 个 `')'`）

#### 示例：`"(()))"`

```text
初始: balance = 0, insertions = 0

i=0: '(' → balance = 0 + 2 = 2, i = 1

i=1: '(' → balance = 2 + 2 = 4, i = 2

i=2: ')' → 检查下一个，也是 ')'
     → balance = 4 - 2 = 2
     → i = 4

i=4: ')' → 检查下一个，到末尾了
     → balance = 2 - 2 = 0
     → insertions = 0 + 1 = 1（需要插入一个 ')' 配对）
     → i = 5

结束: balance = 0
返回: insertions + balance = 1 + 0 = 1
```

**最终字符串：** `"(())))"` （在末尾插入了 1 个 `')'`）

### 为什么这样是最优的？

#### 贪心策略

1. **立即处理**：每次遇到右括号就立即判断是否需要插入
2. **局部最优**：
   - 遇到单独的 `')'` 立即插入一个 `')'` 配对
   - 遇到多余的 `')'` 立即插入 `'('` 匹配
3. **全局最优**：这种贪心策略保证了插入次数最少

#### 证明贪心正确性

- **单独 `')'` 必须插入**：规则要求必须两个连续，别无选择
- **右括号过多必须插入 `'('`**：否则无法平衡
- **延迟处理不会更优**：立即处理可以确保局部平衡，不会影响后续决策

## 复杂度分析

### 时间复杂度

- **O(n)**：遍历字符串一次，每个字符处理时间为常数
- 虽然有 `while` 循环处理 `balance < 0`，但每次 `insertions` 增加后 `balance` 至少增加 2，总次数有限

### 空间复杂度

- **O(1)**：只使用常数个变量

## 核心要点

1. **特殊规则**：每个 `'('` 需要配对**两个连续**的 `')'`
2. **balance 追踪**：记录当前需要多少个 `')'` 来平衡
3. **连续判断**：检查是否有连续的 `'))'`
4. **单独处理**：单独的 `')'` 需要插入配对
5. **负数修正**：`balance < 0` 时需要插入 `'('`
6. **最后补充**：循环结束后补充剩余的 `')'`

## 易错点

### 错误 1：balance 的含义

```cpp
// ❌ 错误：认为 balance 是左括号数量
return insertions + balance * 2;

// ✓ 正确：balance 已经是需要的 ')' 数量
return insertions + balance;
```

### 错误 2：单独 ')' 的处理

```cpp
// ❌ 错误：单独 ')' 只减 1
balance -= 1;

// ✓ 正确：单独 ')' 也要减 2（因为要插入配对的 ')'）
balance -= 2;
insertions++;
```

### 错误 3：balance < 0 的修正

```cpp
// ❌ 错误：修正后 balance = 0
if (balance < 0) {
    insertions++;
    balance = 0;
}

// ✓ 正确：修正后 balance += 2（新插入的 '(' 需要 2 个 ')'）
while (balance < 0) {
    insertions++;
    balance += 2;
}
```
