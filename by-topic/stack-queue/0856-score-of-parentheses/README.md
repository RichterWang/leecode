# 856. Score of Parentheses

- **中文名称**：括号的分数
- **题目链接**：https://leetcode.com/problems/score-of-parentheses/
- **核心思路**：栈模拟自底向上计算，或深度计数法。

## 题目

给定一个平衡括号字符串 `s`，按下述规则计算分数：

- `()` 得 **1** 分
- `AB` 得 **A + B** 分（相邻拼接）
- `(A)` 得 **2 × A** 分（嵌套翻倍）

```text
示例：
"()"         → 1
"(())"       → 2 × 1 = 2
"()()"       → 1 + 1 = 2
"(()(()))"   → 2 × (1 + 2 × 1) = 6
```

## 方法一：栈模拟（直观）

### 核心思路

用栈存储每层的**累积分数**，遇到 `(` 进入新层，遇到 `)` 结算当前层并合并到外层。

栈底的初始 `0` 代表最外层的累积基础，保证了平行括号对（如 `"()()"`）能自动累加。

### 实现

```cpp
int scoreOfParentheses(string s) {
    stack<int> stk;
    stk.push(0);  // 栈底初始分

    for (char c : s) {
        if (c == '(') {
            stk.push(0);  // 进入新层
        } else {
            int v = stk.top(); stk.pop();  // 当前层分数
            int w = stk.top(); stk.pop();  // 外层累积分
            stk.push(w + max(2 * v, 1));   // 合并
        }
    }

    return stk.top();
}
```

### 为什么是 `max(2 * v, 1)`

统一处理两个规则：

| 情况 | v 的值 | `2 × v` | `max(2 × v, 1)` | 对应规则 |
|------|--------|---------|-----------------|---------|
| `()` | 0 | 0 | **1** | `()` 得 1 分 |
| `(A)` | ≥1 | ≥2 | **2 × v** | `(A)` 得 2A 分 |

等价于：

```cpp
if (v == 0) stk.push(w + 1);      // ()
else        stk.push(w + 2 * v);  // (A)
```

但 `max` 更简洁。

### 栈的状态演化

以 `"(()(()))"` 为例：

| 字符 | 操作 | 栈状态 | 说明 |
|------|------|--------|------|
| 初始 | - | `[0]` | 栈底初始分 |
| `(` | push(0) | `[0, 0]` | 进入第一层 |
| `(` | push(0) | `[0, 0, 0]` | 进入第二层 |
| `)` | 结算 | `[0, 1]` | `()` 得 1 分 |
| `(` | push(0) | `[0, 1, 0]` | 第一层内再嵌套 |
| `(` | push(0) | `[0, 1, 0, 0]` | 第三层 |
| `)` | 结算 | `[0, 1, 1]` | `()` 得 1 分 |
| `)` | 结算 | `[0, 3]` | `(())` = 2×1=2，加到前面的 1 → 3 |
| `)` | 结算 | `[6]` | `(3)` = 2×3=6 |

最终 `stk.top() = 6`。

### 为什么栈底需要初始 `0`

处理平行结构时，每对括号的分数累加到栈底：

| 字符 | 栈状态 |
|------|--------|
| 初始 | `[0]` |
| `(` | `[0, 0]` |
| `)` | `[1]` ← 第一个 `()` 得 1 分 |
| `(` | `[1, 0]` |
| `)` | `[2]` ← 第二个 `()` 再加 1 分 |

自动实现了「`AB` 得 `A + B` 分」。

### 复杂度

- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(n)`，最坏情况栈深度等于嵌套层数

## 方法二：深度计数法（最优）

### 核心观察

**只有 `()` 这种原子单元真正贡献分数，外层括号只是不断翻倍。**

每个 `()` 在深度 `d` 时贡献 `2^d` 分。

例如 `"(()(()))"` 中：

```text
( ( ) ( ( ) ) )
  ↑     ↑
  深度1 深度2
  2^1=2 2^2=4
```

总分 = `2 + 4 = 6`。

### 实现

```cpp
int scoreOfParentheses(string s) {
    int ans = 0, depth = 0;
    
    for (int i = 0; i < s.size(); i++) {
        if (s[i] == '(') {
            depth++;
        } else {
            depth--;
            if (s[i-1] == '(') {  // 检测到 ()
                ans += (1 << depth);  // 2^depth
            }
        }
    }
    
    return ans;
}
```

### 为什么只在 `s[i-1] == '('` 时累加

- `s[i] = ')'` 且 `s[i-1] = '('` 时，说明遇到了原子单元 `()`
- 其他 `')'` 只是在闭合外层括号，不直接贡献分数

例如 `"(())"` 中：

| i | s[i] | depth | s[i-1] == '(' ? | 操作 |
|---|------|-------|----------------|------|
| 0 | `(` | 1 | - | - |
| 1 | `(` | 2 | - | - |
| 2 | `)` | 1 | **是** | ans += 2^1 = 2 |
| 3 | `)` | 0 | 否 | 只是闭合外层 |

### 复杂度

- **时间复杂度**：`O(n)`
- **空间复杂度**：`O(1)` ← **比栈法更优**

---

## 两种方法对比

| 方法 | 时间 | 空间 | 优势 |
|------|------|------|------|
| 栈模拟 | O(n) | O(n) | 直观，直接模拟规则的递归结构 |
| 深度计数 | O(n) | O(1) | 最优空间，抓住问题本质 |

**推荐深度计数法**，但栈法更容易理解和推广到其他括号问题。

---

## 思维方式总结

这题有个典型的思维升级过程：

1. **暴力递归**：按规则展开，`O(2^n)` 指数级
2. **栈模拟**：用栈维护层级结构，`O(n)` 时间 `O(n)` 空间
3. **本质简化**：发现只有 `()` 贡献分数，外层只是乘 2 → 深度计数，`O(1)` 空间

**先想清楚「哪些操作真正改变了答案」**，往往能从 `O(n)` 空间降到 `O(1)`。
