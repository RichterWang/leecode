# 2029. Stone Game IX

## 题目信息

- **难度**：Medium
- **分类**：Array, Math, Game Theory
- **链接**：https://leetcode.com/problems/stone-game-ix/

## 题目描述

Alice 和 Bob 轮流从数组 `stones` 中移除一个石子，Alice 先手。

规则如下：

- 如果某个玩家移除石子后，所有已移除石子的价值总和可以被 `3` 整除，那么该玩家立即输掉游戏。
- 如果没有触发上面的失败条件，并且石子已经被全部移除，那么 Bob 直接获胜。
- 双方都采用最优策略，判断 Alice 是否能够获胜。

## 解题思路

这题的关键在于只需要关心每个石子对 `3` 取模后的结果，而不需要关心石子的具体数值。

将所有石子分成三类：

- `cnt[0]`：值对 `3` 取模后为 `0` 的石子个数
- `cnt[1]`：值对 `3` 取模后为 `1` 的石子个数
- `cnt[2]`：值对 `3` 取模后为 `2` 的石子个数

### 分类讨论

#### 1. `cnt[0]` 为偶数

这时余数为 `0` 的石子不会改变关键局面的先后手关系，可以视作对主战场影响抵消。

Alice 想赢，必须同时拥有余数为 `1` 和余数为 `2` 的两类石子可供选择，否则局面会被锁死。

因此判定条件为：

```cpp
cnt[1] > 0 && cnt[2] > 0
```

#### 2. `cnt[0]` 为奇数

这时余数为 `0` 的石子会翻转关键局面的出手顺序。

此时只有当 `cnt[1]` 和 `cnt[2]` 的数量差足够大时，Alice 才能通过先手优势控制节奏。

因此判定条件为：

```cpp
abs(cnt[1] - cnt[2]) > 2
```

## 复杂度

- **时间复杂度**：`O(n)`，只需要一次遍历统计三类石子的数量。
- **空间复杂度**：`O(1)`，只使用长度为 `3` 的计数数组。
