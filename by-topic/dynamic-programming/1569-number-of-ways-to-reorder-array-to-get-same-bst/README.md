# 1569. 将子数组重新排列得到一个二叉搜索树的方案数

## 题目信息

- **难度**：Hard
- **分类**：Dynamic Programming, Tree, Binary Search Tree, Combinatorics, Recursion
- **链接**：https://leetcode.com/problems/number-of-ways-to-reorder-array-to-get-same-bst/

## 题目描述

给你一个数组 `nums` 表示 `1` 到 `n` 的一个排列。我们按照元素在 `nums` 中的顺序依次插入一个初始为空的二叉搜索树（BST）。请你统计将 `nums` 重新排序后，统计满足如下条件的方案数：重排后得到的二叉搜索树与 `nums` 原本数字顺序得到的二叉搜索树**相同**。

比方说，给你 `nums = [2,1,3]`，我们得到一棵 `2` 为根，`1` 为左孩子，`3` 为右孩子的树。数组 `[2,3,1]` 也能得到相同的 BST，但 `[3,2,1]` 会得到一棵不同的 BST。

请你返回重排 `nums` 后，与原数组 `nums` 得到相同二叉搜索树的方案数。

由于答案可能会很大，请将结果对 `10^9 + 7` **取余数**。

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= nums.length`
- `nums` 中所有数**互不相同**

## 核心概念

### 数组如何表示 BST？

数组 `nums` 表示**按顺序插入 BST 的元素序列**，不是选择其中的元素，而是**全部元素依次插入**。

#### BST 插入规则

```
1. 第一个元素成为根节点
2. 后续每个元素：
   - 从根开始比较
   - 如果 < 当前节点，往左子树走
   - 如果 > 当前节点，往右子树走
   - 找到空位置，插入
```

#### 示例：`nums = [2, 1, 3]`

```
Step 1: 插入 2
    2

Step 2: 插入 1 (1 < 2，往左)
    2
   /
  1

Step 3: 插入 3 (3 > 2，往右)
    2
   / \
  1   3
```

#### 重排后的数组 `[2, 3, 1]`

```
Step 1: 插入 2
    2

Step 2: 插入 3 (3 > 2，往右)
    2
     \
      3

Step 3: 插入 1 (1 < 2，往左)
    2
   / \
  1   3
```

**结果：相同的 BST！** ✅

### 为什么不同的顺序能得到相同的 BST？

**关键观察**：
1. **第一个元素决定根节点**（必须相同）
2. **小于根的元素进入左子树，大于根的元素进入右子树**（由大小关系决定）
3. **左右子树内部的相对顺序不变，BST 结构就相同**

## 解题思路

### 方法：递归 + 组合数学

#### 核心公式

```
ways(nums) = ways(left) × ways(right) × C(|left| + |right|, |left|)
```

其中：
- `left`：所有小于 `nums[0]` 的元素（保持相对顺序）
- `right`：所有大于 `nums[0]` 的元素（保持相对顺序）
- `C(n, k)`：组合数，表示从 n 个位置中选 k 个给左子树的方案数

#### 为什么是组合数？

假设左子树 2 个元素，右子树 3 个元素：
- 总共 5 个位置（根之后）
- 从 5 个位置中选 2 个给左子树：C(5, 2) = 10 种方案
- 剩下的位置自动给右子树
- **只要左右子树内部相对顺序不变，BST 就相同**

#### 算法步骤

**1. 预处理组合数（Pascal 三角）**

使用动态规划预处理所有可能用到的组合数：

```cpp
comb[i][j] = C(i, j)  // 从 i 个元素中选 j 个的方案数
```

递推公式（Pascal 三角）：
```
C(i, j) = C(i-1, j-1) + C(i-1, j)
```

可视化（杨辉三角）：
```
行 i=0:        1
行 i=1:      1   1
行 i=2:    1   2   1
行 i=3:  1   3   3   1
行 i=4: 1  4   6   4  1
行 i=5: 1  5  10  10  5  1
```

**为什么用 DP 而不是直接算阶乘？**

直接算 `C(n,k) = n! / (k! × (n-k)!)` 有以下问题：
- 阶乘会溢出（`1000!` 巨大）
- 除法取模需要逆元（复杂）
- 效率低（每次重新计算）

DP 预处理的优点：
- 无溢出（每步取模）
- 无除法（只用加法）
- 高效查询（预处理 O(n²)，查询 O(1)）

**2. 递归计算方案数**

```cpp
function<long long(vector<int>&)> dfs = [&](vector<int>& nums) -> long long {
    if (n <= 1) return 1;  // 边界：空或单节点
    
    int root = nums[0];
    vector<int> left, right;
    
    // 分割左右子树
    for (int i = 1; i < n; i++) {
        if (nums[i] < root) left.push_back(nums[i]);
        else right.push_back(nums[i]);
    }
    
    // 递归计算
    long long left_ways = dfs(left);
    long long right_ways = dfs(right);
    
    // 组合数：从 total 个位置中选 left_size 个
    int total = left.size() + right.size();
    long long interleave = comb[total][left.size()];
    
    return left_ways * right_ways % MOD * interleave % MOD;
};
```

**3. 返回答案**

```cpp
return (dfs(nums) - 1 + MOD) % MOD;
```

**注意**：题目要求"重排后"的方案数，不包括原序列，所以要减 1。

### 复杂度分析

**时间复杂度：** O(n²)
- 预处理组合数：O(n²)（双重循环）
- 递归深度最多 n 层
- 每层 O(n) 的分割操作
- 总体：O(n²)

**空间复杂度：** O(n²)
- 组合数表：O(n²)
- 递归栈：O(n)
- 临时数组：O(n)

## 示例推演

### `nums = [3, 4, 5, 1, 2]`

```
根 = 3
左子树 = [1, 2]（所有 < 3 的元素）
右子树 = [4, 5]（所有 > 3 的元素）

递归计算：
ways([1, 2]) = 1（只有一种相对顺序）
ways([4, 5]) = 1（只有一种相对顺序）

组合数：C(4, 2) = 6
（从 4 个位置选 2 个给左子树）

ways([3,4,5,1,2]) = 1 × 1 × 6 = 6
答案 = 6 - 1 = 5
```

**5 种重排方案验证**：
1. `[3, 1, 2, 4, 5]`
2. `[3, 1, 4, 2, 5]`
3. `[3, 1, 4, 5, 2]`
4. `[3, 4, 1, 2, 5]`
5. `[3, 4, 1, 5, 2]`

（原序列 `[3, 4, 5, 1, 2]` 不算）

## 易错点

### 1. 模数错误

```cpp
// ❌ 错误
int mod = 1e9;

// ✅ 正确
int mod = 1e9 + 7;
```

### 2. 乘法溢出

三个数相乘时要分步取模：

```cpp
// ❌ 错误：可能溢出
return left_ways * right_ways * interleave % MOD;

// ✅ 正确
return left_ways * right_ways % MOD * interleave % MOD;
```

### 3. 忘记减 1

题目问的是"重排后"得到相同 BST 的方案数，**原序列不算**。

```cpp
// ✅ 正确
return (dfs(nums) - 1 + MOD) % MOD;
```

加 `MOD` 是为了防止结果为负数（虽然理论上 `dfs(nums) >= 1`）。

### 4. 组合数索引越界

```cpp
// 确保索引合法
int total = n - 1;  // 除去根节点
int left_size = static_cast<int>(left.size());
// comb[total][left_size] 必须满足 left_size <= total
```

### 5. Lambda 递归写法

Lambda 递归必须使用 `std::function`：

```cpp
// ❌ 错误：auto 无法递归
auto dfs = [&](vector<int>& nums) { ... dfs(...); };

// ✅ 正确
function<long long(vector<int>&)> dfs = [&](vector<int>& nums) -> long long { 
    ... dfs(...); 
};
```

## 相关知识点

### Pascal 三角（杨辉三角）

组合数 `C(n, k)` 的性质：

1. **递推公式**：`C(n, k) = C(n-1, k-1) + C(n-1, k)`
2. **对称性**：`C(n, k) = C(n, n-k)`
3. **边界**：`C(n, 0) = C(n, n) = 1`

### BST 的性质

1. **左子树所有节点 < 根节点 < 右子树所有节点**
2. **中序遍历得到有序序列**
3. **插入顺序不同，树结构可能不同**

### 组合数学应用

这道题的本质是：**多重集合的排列数**。

假设有 `m` 个红球和 `n` 个蓝球，问有多少种排列方式？

答案：`C(m+n, m) = (m+n)! / (m! × n!)`
