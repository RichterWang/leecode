# 1621. Number of Sets of K Non-Overlapping Line Segments

## 题目信息

- **难度**：Medium
- **分类**：Math, Dynamic Programming, Combinatorics
- **链接**：https://leetcode.com/problems/number-of-sets-of-k-non-overlapping-line-segments/

## 题目描述

给你一维空间的 `n` 个点，其中第 `i` 个点（编号从 0 到 n-1）位于 `x = i` 处，请你找到**恰好** `k` 个不重叠线段且每个线段至少覆盖两个点的方案数。

线段的两个端点必须都是**整数坐标**。这 `k` 个线段不需要全部覆盖全部 `n` 个点，且它们的端点**可以**重合。

请你返回 `k` 个不重叠线段的方案数。由于答案可能很大，请将结果对 `10^9 + 7` 取余后返回。

## 解题思路

### 方法：动态规划 + 前缀和优化

#### 状态定义

- `dp[i][j]`：用前 `i` 个点（点 0 到点 i-1）形成 `j` 条线段的方案数
- `prefix[i][j]`：前缀和，即 `dp[0][j] + dp[1][j] + ... + dp[i][j]`

#### 状态转移

对于 `dp[i][j]`，有两种选择：

1. **不使用第 i 个点**（点 i-1）作为任何线段的右端点
   - 方案数：`dp[i-1][j]`

2. **使用第 i 个点作为某条线段的右端点**
   - 需要枚举这条线段的左端点位置
   - 假设线段为 `[L, i-1]`，则 L 可以是 0 到 i-2 中的任意位置
   - 前面需要已经形成 `j-1` 条线段
   - 由于需要对所有可能的 L 求和，可以用前缀和优化：`prefix[i-1][j-1]`

**状态转移方程**：
```
dp[i][j] = dp[i-1][j] + prefix[i-1][j-1]
```

**前缀和更新**：
```
prefix[i][j] = dp[i][j] + prefix[i-1][j]
```

#### 初始化

- `dp[i][0] = 1`：不选任何线段，方案数为 1
- `prefix[0][i]` 初始化为对应的累加值

#### 关键点

1. **线段可以共享端点**：两条线段 `[a, b]` 和 `[b, c]` 是合法的
2. **每条线段至少覆盖 2 个点**：线段 `[i, j]` 要求 `j > i`
3. **不重叠**：线段不能有交叉的内部部分（端点可以重合）

### 数学方法（替代解法）

这道题也可以用组合数学公式直接计算：

```
答案 = C(n + k - 1, 2k)
```

其中 `C(n, m)` 表示组合数"从 n 个元素中选 m 个"。

这个公式来自于将问题转化为：在 `n` 个点中选择 `2k` 个端点（允许重复选择），并配对成 `k` 条线段。

## 复杂度

- **时间复杂度**：`O(n * k)`
  - 两层循环，每次操作为 O(1)
- **空间复杂度**：`O(n * k)`
  - 需要两个二维数组 `dp` 和 `prefix`

## 示例

### 示例 1
```
输入：n = 4, k = 2
输出：5
解释：5 种方案为：
1. [0,1] + [2,3]
2. [0,1] + [1,2]
3. [0,2] + [2,3]
4. [1,2] + [2,3]
5. [0,1] + [1,3]
```

### 示例 2
```
输入：n = 3, k = 1
输出：3
解释：3 种方案为：
1. [0,1]
2. [0,2]
3. [1,2]
```
