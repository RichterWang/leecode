# 2333. 最小差值平方和

## 题目描述

给你两个下标从 0 开始的整数数组 `nums1` 和 `nums2`，长度为 `n`。

数组 `nums1` 和 `nums2` 的**差值平方和**定义为所有满足 `0 <= i < n` 的 `(nums1[i] - nums2[i])²` 之和。

同时给你两个正整数 `k1` 和 `k2`。你可以将 `nums1` 中的任意元素 `+1` 或者 `-1` 至多 `k1` 次。类似的，你可以将 `nums2` 中的任意元素 `+1` 或者 `-1` 至多 `k2` 次。

请你返回修改数组 `nums1` 至多 `k1` 次且修改数组 `nums2` 至多 `k2` 次后的最小**差值平方和**。

**注意**：你可以将数组中的元素变成**负**整数。

## 示例

### 示例 1
```
输入：nums1 = [1,2,3,4], nums2 = [2,10,20,19], k1 = 0, k2 = 0
输出：579
解释：nums1 和 nums2 中的元素不能修改，因为 k1 = 0 和 k2 = 0。
差值平方和为：(1 - 2)² + (2 - 10)² + (3 - 20)² + (4 - 19)² = 579
```

### 示例 2
```
输入：nums1 = [1,4,10,12], nums2 = [5,8,6,9], k1 = 1, k2 = 1
输出：43
解释：一种得到最小差值平方和的方式为：
- 将 nums1[0] 增加一次
- 将 nums2[2] 增加一次
最小差值平方和为：(2 - 5)² + (4 - 8)² + (10 - 7)² + (12 - 9)² = 43
```

## 约束条件

- `n == nums1.length == nums2.length`
- `1 <= n <= 10⁵`
- `0 <= nums1[i], nums2[i] <= 10⁵`
- `0 <= k1, k2 <= 10⁹`

## 解题思路

### 核心思想

1. **问题转化**：对 `nums1[i]` 增加 1 或对 `nums2[i]` 减少 1，效果都是让差值减少 1，所以可以合并操作次数 `k = k1 + k2`

2. **贪心策略**：因为目标是最小化平方和，而平方函数是凸函数，所以优先减少最大的差值能获得最大收益
   - 例如：(10)² = 100，(9)² = 81，减少了 19
   - 但 (5)² = 25，(4)² = 16，只减少了 9

3. **批量处理优化**：不逐个减少差值，而是批量将最大的几个差值一起降到下一个阶梯

### 算法步骤

1. **计算差值数组**：`diff[i] = |nums1[i] - nums2[i]|`
2. **提前优化**：如果 `sum(diff) <= k`，直接返回 0
3. **降序排序**：将差值从大到小排序
4. **批量降低阶梯**：
   - 对于前 `count` 个最大的元素，计算降到下一个阶梯需要的操作数
   - 如果 k 够用，就全部降到下一个阶梯
   - 如果 k 不够，就平均分配给这些元素
5. **处理剩余 k**：将剩余的操作次数分配给前 k 个元素（注意边界检查）
6. **计算平方和**：返回最终的差值平方和

### 关键技巧：批量降低

对于排序后的差值数组 `[10, 8, 8, 5, 3]`：

**朴素做法**（会超时）：
```cpp
for (int op = 0; op < k; op++) {
    找到最大差值，减少 1
}
// 时间复杂度：O(k·n)
```

**优化做法**（批量处理）：
```cpp
// 把前 3 个元素 [10, 8, 8] 一起降到 5
// 一次性完成多次操作
// 时间复杂度：O(n log n)
```

### 代码实现要点

#### 1. 批量降低的核心逻辑

```cpp
for (int i = 0; i < n && k > 0; i++) {
    long long next = (i + 1 < n) ? diff[i + 1] : 0;  // 下一个阶梯
    long long count = i + 1;                          // 要处理的元素数量
    long long reduce = min(k / count, diff[i] - next); // 能降低多少
    
    // 批量降低前 count 个元素
    for (int j = 0; j <= i; j++) {
        diff[j] -= reduce;
    }
    k -= reduce * count;
}
```

#### 2. 边界检查的重要性

```cpp
// 必须限制循环次数，防止数组越界
if (k > 0) {
    for (int i = 0; i < min(k, (long long)n); i++) {
        diff[i]--;
    }
}
```

**为什么需要边界检查？**

当所有 diff 降到 0 后循环提前退出，但 k 可能还有大量剩余：

```
diff = [5, 5, 5]  (n = 3)
k = 1000

降到 [0, 0, 0] 后，k = 985 剩余
如果不加 min(k, n)，会访问 diff[3], diff[4], ..., diff[985] → 越界！
```

## 时间复杂度

- **排序**：O(n log n)
- **批量降低**：O(n²) 最坏情况（内层循环更新元素）
- **总体**：O(n²)

**注意**：此解法在极端情况下可能超时，更优的解法需要用计数/频率优化。

## 空间复杂度

- O(n)：用于存储差值数组

## 优化解法：频率计数 + 贪心（推荐）

### 核心优化思路

基础解法的瓶颈在于**内层循环逐个更新元素**：

```cpp
for (int j = 0; j <= i; j++) {
    diff[j] -= reduce;  // O(n) 的内层循环
}
```

**关键洞察**：我们不需要维护每个位置的差值，只需要知道**每个差值有多少个**！

### 优化算法步骤

#### 1. 用频率 map 代替数组

```cpp
map<long long, long long> freq;  // {差值: 出现次数}
for (int i = 0; i < n; i++) {
    long long d = abs(nums1[i] - nums2[i]);
    freq[d]++;
}
```

#### 2. 从大到小贪心降低

```cpp
while (k > 0) {
    auto it = prev(freq.end());      // 获取最大差值的迭代器
    long long maxDiff = it->first;   // 最大差值
    long long count = it->second;    // 该差值的数量
    
    if (maxDiff == 0) break;
    
    // 找下一个阶梯（次大的差值）
    long long nextDiff = (it != freq.begin()) ? prev(it)->first : 0;
    
    // 计算降到下一个阶梯需要的操作数
    long long gap = maxDiff - nextDiff;
    long long needed = gap * count;
    
    if (k >= needed) {
        // k 够用，完全降到下一个阶梯
        freq.erase(it);
        freq[nextDiff] += count;
        k -= needed;
    } else {
        // k 不够，只能部分降低
        long long reduce = k / count;
        long long remainder = k % count;
        
        freq.erase(it);
        if (remainder > 0) {
            // 有余数，需要分成两组
            freq[maxDiff - reduce - 1] += remainder;
            freq[maxDiff - reduce] += (count - remainder);
        } else {
            freq[maxDiff - reduce] += count;
        }
        k = 0;
    }
}
```

### 关键实现细节

#### prev() 函数

`prev()` 是 C++ STL 的迭代器辅助函数（`<iterator>` 头文件）：

```cpp
auto it = prev(freq.end());  // 返回最后一个有效元素的迭代器
```

因为 `std::map` 是自动升序排序的：
- `freq.begin()` 指向最小键
- `freq.end()` 指向末尾哨兵位置（无效）
- `prev(freq.end())` 指向最后一个有效元素，即**最大键**

#### 处理余数的逻辑

当 k 不能整除 count 时，需要将元素分成两组：

```cpp
// 例如：10 个差值为 5 的元素，k = 23
reduce = 23 / 10 = 2
remainder = 23 % 10 = 3

// 结果：
// - 3 个元素降低 3（从 5 降到 2）
// - 7 个元素降低 2（从 5 降到 3）
freq[5 - 2 - 1] += 3  // freq[2] += 3
freq[5 - 2] += 7      // freq[3] += 7
```

### 优化效果对比

| 解法 | 时间复杂度 | 空间复杂度 | 是否超时 |
|------|-----------|-----------|---------|
| 基础解法 | O(n²) | O(n) | 极端情况超时 ✗ |
| 优化解法 | O(n log n) | O(m)，m ≤ n | 通过所有测试 ✓ |

### 优化后的时间复杂度

- **统计频率**：O(n)
- **贪心降低**：O(m log m)，其中 m 是不同差值的个数（m ≤ n）
- **计算平方和**：O(m)
- **总体**：O(n + m log m) = **O(n log n)** ✓

### 优化后的空间复杂度

- O(m)：用于存储频率 map，m 是不同差值的个数

### 为什么快这么多？

**基础做法（O(n²)）**：
```
每次更新前 count 个元素
最坏情况：1 + 2 + 3 + ... + n = O(n²)
```

**优化做法（O(n log n)）**：
```
只操作 map 的键值对
最多 n 个不同的差值
每次 map 操作 O(log n)
总共 O(n log n)
```
