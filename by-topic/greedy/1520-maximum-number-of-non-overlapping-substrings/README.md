# 1520. 最多的不重叠子字符串

## 题目描述

给你一个只包含小写字母的字符串 `s`，你需要找到 `s` 中最多数目的非空子字符串，满足如下条件：

1. 这些字符串之间互不重叠，也就是说对于任意两个子字符串 `s[i..j]` 和 `s[x..y]`，要么 `j < x` 要么 `i > y`
2. 如果一个子字符串包含字符 `char`，那么 `s` 中所有 `char` 字符都应该在这个子字符串中

请你找到满足上述条件的最多子字符串数目。如果有多个解法有相同的子字符串数目，请返回这些子字符串总长度最小的一个解。可以证明最小总长度解是唯一的。

请注意，你可以以**任意**顺序返回最优解的子字符串。

**示例 1：**
```
输入：s = "adefaddaccc"
输出：["e","f","ccc"]
解释：下面的子字符串满足所有条件：
  [
    "adefaddaccc"
    "adefaddaccc",
    "adefaddaccc",
    "adefaddaccc",
    "adefaddaccc"
  ]
如果我们选择 ["e","f","ccc"]，答案的长度是 1 + 1 + 3 = 5，而选择 ["adefadda","accc"] 的长度是 8 + 4 = 12。
所以返回 ["e","f","ccc"]。
```

**示例 2：**
```
输入：s = "abbaccd"
输出：["d","bb","cc"]
解释：注意，虽然 "abba" 可以满足所有条件，但由于 ["d","bb","cc"] 的长度更短，所以返回它。
```

**提示：**
- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母

## 解题思路

本题是一道**贪心算法 + 区间调度**问题。核心思想是：

### 1. 预处理：找到每个字符的首次和末次出现位置

```cpp
vector<int> first(26, -1), last(26, -1);
for(int i = 0; i < n; i++) {
    int c = s[i] - 'a';
    if(first[c] == -1) first[c] = i;
    last[c] = i;
}
```

### 2. 扩散算法：计算有效区间

**关键点**：初始的 `[first[c], last[c]]` 只保证字符 `c` 的所有出现都在区间内，但**区间内可能包含其他字符**，这些字符可能在区间外也有出现，违反了题目约束。

**扩散过程**：
```cpp
int l = first[c], r = last[c];
for(int i = l; i <= r; i++) {
    int ch = s[i] - 'a';
    if(first[ch] < l || last[ch] > r) {
        // 区间内的字符 ch 在区间外也有出现，需要扩散
        l = min(l, first[ch]);
        r = max(r, last[ch]);
        i = l;  // 重新从头扫描（可能有连锁反应）
    }
}
```

**为什么要重新扫描？**

扩散后的区间可能包含新的字符，这些新字符可能又引发新的扩散。例如：
- `s = "abcabc"`，检查字符 `'a'` 的区间 `[0, 3]`
- 包含 `'b'` → 扩散到 `[0, 4]`（因为 `'b'` 在位置 4）
- 现在 `[0, 4]` 又包含新的 `'c'` → 继续扩散到 `[0, 5]`

### 3. 去重

不同的字符可能扩散到相同的区间，需要去重：
```cpp
sort(intervals.begin(), intervals.end());
intervals.erase(unique(intervals.begin(), intervals.end()), intervals.end());
```

### 4. 贪心选择：区间调度问题

这是经典的**区间调度问题**，贪心策略是：
- 按**右端点**从小到大排序（右端点越早，为后续留的空间越大）
- 依次选择不重叠的区间

```cpp
sort(intervals.begin(), intervals.end(), [](const auto& a, const auto& b){
    if(a.second != b.second) return a.second < b.second;  // 右端点优先
    return (a.second - a.first) < (b.second - b.first);   // 长度次要
});

int lastEnd = -1;
for(auto [l, r] : intervals) {
    if(l > lastEnd) {  // 当前区间不与已选区间重叠
        result.push_back(s.substr(l, r - l + 1));
        lastEnd = r;
    }
}
```

**为什么右端点优先是对的？**

反例说明长度优先不对：
- `s = "abbaccd"`，区间有 `[1,2]="bb"`, `[4,5]="cc"`, `[6,6]="d"`
- 如果按长度排序先选 `"d"` (位置6)，会导致前面的 `"bb"` 和 `"cc"` 无法选择
- 按右端点排序先选 `"bb"` (右端点2)，可以依次选择所有三个区间

### 复杂度分析

- **时间复杂度**：O(n × 26) ≈ O(n)
  - 预处理：O(n)
  - 扩散：最坏情况每个字符扫描整个字符串，但总共只有 26 个字母
  - 排序：O(26 log 26) ≈ O(1)
  - 贪心选择：O(26)

- **空间复杂度**：O(26) ≈ O(1)

## 关键点总结

1. **扩散算法**：保证每个有效区间满足题目约束（包含某字符则包含其所有出现）
2. **区间调度**：按右端点贪心选择，保证选择最多的不重叠区间
3. **重新扫描**：扩散时需要 `i = l` 重新扫描，因为可能有连锁反应
