# 2472. 不重叠回文子字符串的最大数目

**难度**：Medium　**标签**：贪心、字符串、双指针

## 题目描述

给你一个字符串 `s` 和一个**正**整数 `k`。

从字符串 `s` 中选出一组满足下述条件且**不重叠**的子字符串：
- 每个子字符串的长度**至少**为 `k`
- 每个子字符串是一个**回文串**

返回最优方案中能选择的子字符串的**最大**数目。

**子字符串**是字符串中一个连续的字符序列。

### 示例 1

```text
输入：s = "abaccdbbd", k = 3
输出：1
解释：可以选择 s = "aba" 或 s = "dbbd"。最多选择 1 个不重叠的回文子字符串。
```

### 示例 2

```text
输入：s = "adbcda", k = 2
输出：0
解释：没有长度至少为 2 的回文子字符串。
```

### 提示

- `1 <= k <= s.length <= 2000`
- `s` 仅由小写英文字母组成

## 核心思路：贪心算法

### 关键洞察

这道题的本质是**区间调度问题**的变体：
1. 找到所有长度 ≥ k 的回文子串
2. 选择尽可能多的**不重叠**子串

关键的贪心策略是：**优先选择尽可能短的回文串**。

### 为什么只需要检查长度 k 和 k+1？

假设存在一个长度为 `len > k+1` 的最优回文串，我们可以证明：
- 要么可以用更短的回文串替代
- 要么不会影响最终答案

因此，贪心策略是：**从左到右扫描，优先选择长度为 k 的回文串，其次选择长度为 k+1 的回文串**。

为什么这样是最优的？
1. 更短的回文串占用更少的空间
2. 为后续留下更多的选择机会
3. 长度 k 的回文串已经满足"至少为 k"的要求

## 算法步骤

1. 从位置 `i = 0` 开始扫描字符串
2. 对于当前位置 `i`：
   - **优先**检查 `s[i...i+k-1]` 是否是回文（长度 k）
     - 如果是，选择它，跳到 `i = i + k`
   - **其次**检查 `s[i...i+k]` 是否是回文（长度 k+1）
     - 如果是，选择它，跳到 `i = i + k + 1`
   - 如果都不是回文，移动到下一个位置 `i++`
3. 重复直到遍历完整个字符串

## 代码实现

```cpp
class Solution {
public:
    int maxPalindromes(string s, int k) {
        int n = s.size();
        int count = 0;
        int i = 0;
        
        while (i < n) {
            // 优先检查长度为 k 的回文串
            if (i + k <= n && isPalindrome(s, i, i + k - 1)) {
                count++;
                i += k;  // 跳过这个回文串
            }
            // 其次检查长度为 k+1 的回文串
            else if (i + k + 1 <= n && isPalindrome(s, i, i + k)) {
                count++;
                i += k + 1;  // 跳过这个回文串
            }
            // 当前位置找不到合适的回文串，移动到下一个位置
            else {
                i++;
            }
        }
        
        return count;
    }

private:
    // 判断 s[left...right] 是否是回文
    bool isPalindrome(const string& s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) return false;
            left++;
            right--;
        }
        return true;
    }
};
```

## 为什么这个贪心策略是正确的？

### 反证法证明

假设存在一个更优的解，它在某个位置 `i` 跳过了长度为 `k` 的回文串 `P1`，选择了后面的回文串 `P2`。

**情况 1**：`P2` 的起始位置 ≥ `i + k`
- 如果我们选择 `P1`，从 `i + k` 开始，`P2` 仍然可以被选择
- 因此选择 `P1` 不会让结果变差

**情况 2**：`P2` 的起始位置 < `i + k`（与 `P1` 重叠）
- 那么 `P2` 必然比 `P1` 更长（因为 `P1` 长度为 k，是最短的）
- `P2` 占用的空间更多，为后续留下的空间更少
- 这不可能是最优解

因此，贪心策略是最优的。

## 复杂度分析

- **时间复杂度**：`O(n * k)`
  - 外层循环：最多遍历 `n` 个位置
  - 每次判断回文：`O(k)` 或 `O(k+1)` = `O(k)`
  - 总时间：`O(n * k)`

- **空间复杂度**：`O(1)`
  - 只使用常数个变量
  - 没有额外的数据结构

## 边界情况

### 1. 没有回文串

```text
s = "abcd", k = 2
输出：0
```

所有位置都找不到回文串，返回 0。

### 2. 整个字符串是回文

```text
s = "aba", k = 3
输出：1
```

整个字符串就是一个回文串，选择它。

### 3. k = 1

```text
s = "abcde", k = 1
输出：5
```

每个单字符都是回文，可以选择所有字符。

### 4. 多个不重叠的回文

```text
s = "aaabaaacaaa", k = 3
输出：3
```

可以选择 `"aaa"`, `"aaa"`, `"aaa"`。

## 常见错误

### 错误 1：检查所有长度的回文串

```cpp
// ❌ 检查所有长度 >= k 的回文串
for (int len = k; len <= n; len++) {
    if (isPalindrome(s, i, i + len - 1)) {
        count++;
        i += len;
        break;
    }
}
```

这样会导致选择过长的回文串，不是最优的。

**正确做法**：只检查长度 k 和 k+1。

### 错误 2：动态规划但忽略贪心性质

```cpp
// ❌ 用 DP 但没有利用贪心性质
vector<int> dp(n + 1, 0);
for (int i = 0; i < n; i++) {
    for (int j = i + k; j <= n; j++) {
        if (isPalindrome(s, i, j - 1)) {
            dp[j] = max(dp[j], dp[i] + 1);
        }
    }
}
```

虽然这样也能得到正确答案，但时间复杂度是 `O(n^2 * k)`，比贪心慢。

### 错误 3：回文判断错误

```cpp
// ❌ right 指针向右移动
bool isPalindrome(const string& s, int left, int right) {
    while (left < right) {
        if (s[left] != s[right]) return false;
        left++;
        right++;  // ❌ 应该是 right--
    }
    return true;
}
```

右指针应该**向左移动**，不是向右。

### 错误 4：边界检查错误

```cpp
// ❌ 没有检查边界
if (isPalindrome(s, i, i + k - 1)) {  // 可能越界
    count++;
    i += k;
}
```

应该先检查 `i + k <= n`，再调用 `isPalindrome`。

## 优化与变体

### 优化 1：预处理回文信息

如果需要多次查询，可以用 Manacher 算法预处理所有回文串的信息，时间复杂度 `O(n)`。

但对于这道题的数据规模（`n ≤ 2000`），直接判断就够了。

### 优化 2：只检查奇数长度或偶数长度

根据 `k` 的奇偶性，可以只检查特定长度的回文串：
- 如果 `k` 是奇数，优先检查奇数长度
- 如果 `k` 是偶数，优先检查偶数长度

但这个优化带来的收益很小，代码反而更复杂。

### 变体：允许重叠

如果允许重叠，问题变成：找到所有长度 ≥ k 的回文串的数量。

这时可以用动态规划：
```cpp
dp[i] = 前 i 个字符中回文串的最大数量
```

## 总结

这道题的关键是：
1. **识别出这是区间调度问题**
2. **贪心策略**：优先选择短的回文串
3. **只需检查长度 k 和 k+1**
4. **从左到右扫描，遇到就选择**

时间复杂度 `O(n * k)`，空间复杂度 `O(1)`，代码简洁高效。
