# 字符串匹配专题

## 题目信息

- **难度**：基础算法专题
- **分类**：String
- **包含方法**：暴力匹配、双指针、KMP

## 题目描述

在主串 `text` 中查找模式串 `pattern` 第一次出现的位置。找到返回起始下标，找不到返回 `-1`。

## 解题思路

### 方法一：暴力匹配

枚举主串每一个可能的起点，从该起点开始逐字符和模式串比对。

**时间复杂度**：O(n * m)  
**空间复杂度**：O(1)

### 方法二：双指针

用两个指针同步推进，失配时把主串指针回退到上一次起点的下一位，模式串从头开始。

**时间复杂度**：O(n * m)  
**空间复杂度**：O(1)

### 方法三：KMP

先为模式串构造 LPS 数组，失配时不让主串回退，而是让模式串跳到合理位置继续比较。

**时间复杂度**：O(n + m)  
**空间复杂度**：O(m)
