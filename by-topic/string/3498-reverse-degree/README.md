# 3498. 字符串的反转度

## 题目描述

给你一个字符串 `s`，计算其**反转度**。

反转度的计算方法如下：

1. 对于每个字符，将其在**反转字母表**中的位置（`'a' = 26`, `'b' = 25`, ..., `'z' = 1`）与其在字符串中的位置（下标从 `1` 开始）相乘。
2. 将这些乘积加起来，得到字符串中所有字符的和。
3. 返回反转度。

### 示例

**示例 1：**
```
输入：s = "abc"
输出：148
解释：
- 'a' (位置 1)：26 × 1 = 26
- 'b' (位置 2)：25 × 2 = 50
- 'c' (位置 3)：24 × 3 = 72
- 总和：26 + 50 + 72 = 148
```

**示例 2：**
```
输入：s = "z"
输出：1
解释：
- 'z' (位置 1)：1 × 1 = 1
```

### 约束条件

- `1 <= s.length <= 1000`
- `s` 只包含小写英文字母

## 解题思路

这是一道简单的字符串处理题，核心在于正确计算反转字母表的位置。

### 算法步骤

1. **计算反转位置**：对于字符 `c`，其在反转字母表中的位置为 `26 - (c - 'a') = 26 - c + 'a'`
   - `'a'` → `26 - 0 = 26`
   - `'b'` → `26 - 1 = 25`
   - `'z'` → `26 - 25 = 1`

2. **遍历字符串**：对于每个下标 `i`（从 0 开始），将反转位置乘以 `(i + 1)`（位置从 1 开始）

3. **累加结果**：将所有乘积累加得到最终答案

### 复杂度分析

- **时间复杂度**：O(n)，其中 n 是字符串长度，需要遍历一次字符串
- **空间复杂度**：O(1)，只使用常数额外空间

### 代码实现

```cpp
class Solution {
public:
    int reverseDegree(string s) {
        int n = static_cast<int>(s.size());
        if(n == 0) return 0;

        int answer = 0;
        
        for(int i = 0; i < n; i++) {
            answer += (26 - s[i] + 'a') * (i + 1);
        }

        return answer;
    }
};
```

### 关键点

- 反转位置计算公式：`26 - s[i] + 'a'`
- 位置下标转换：数组下标 `i` 对应题目中的位置 `i + 1`
- 整数范围：最坏情况下（长度 1000，全是 'a'），结果约为 13,013,000，在 int 范围内
